# СТАРТ—ФАКТ

Демонстрационный инструмент контроля фактической адаптации новых сотрудников.

Показывает, получил ли новый сотрудник нужный **результат** по каждой задаче адаптации,
а не просто закрыта ли задача в Битрикс24. Ответ «Нет» или «Частично» — это сигнал
для проверки процесса, а не оценка сотрудника.

## Демо

<https://webcraftdigital6-debug.github.io/test1/>

Все сотрудники, ответы и статусы вымышлены. Корпоративные системы не подключены,
данные хранятся только в localStorage браузера.

## Экраны

| Экран | Что делает |
| --- | --- |
| **Обзор адаптации** | Сводка по выборке, таблица сотрудников с прогрессом по подтверждённым результатам и список расхождений, требующих внимания |
| **Кабинет новичка** | Задачи сотрудника и его отметки: «Да / Частично / Нет» с комментарием |
| **Расхождения** | Очередь расхождений между статусом задачи и ответом новичка, карточка случая, журнал и передача ответственному |
| **Аналитика процесса** | Состав задач по подразделениям и распределение расхождений по категориям, подразделениям и этапам адаптации |

## Запуск локально

Приложение — один статический файл без сборки. Достаточно открыть `index.html` в браузере.

```bash
# любой статический сервер
npx serve .
# или
python -m http.server 8000
```

## Стек

- Один HTML-файл с встроенными стилями и логикой, без зависимостей и сборки
- IBM Plex Sans + IBM Plex Mono (подгружаются с Google Fonts, есть системный фолбэк)
- Vanilla JS, состояние в `localStorage` (ключ `start-fakt-demo-v1`)

## Деплой

GitHub Pages, публикация из ветки `main`, корень репозитория.
Сборка — обычная статическая выгрузка `index.html`.
